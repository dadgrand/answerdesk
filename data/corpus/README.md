# Demo corpus (synthetic, CC0-1.0)

This directory is **generated**. Do not hand-edit a file here: the manifest is a pure
function of the generator seed and the chunking profile, and a test
(`tests/integration/ingest/test_demo_corpus.py::test_checked_in_corpus_matches_a_fresh_build`)
fails when the committed tree stops matching a fresh build.

## What is here

| Path | Committed | Content |
|---|---|---|
| `manifest.json` | yes | provenance: per-source `sha256`, `byte_size`, `license`, `language`; counts and chunk statistics; dedup decisions; generator seed; corpus version |
| `docs/<locale>/*.md` | yes | knowledge-base articles in `ru, tg, uz, ky, tr, zh` (six support intents) |
| `queries/queries.jsonl` | yes | customer questions per article, with the perturbation class that was injected and a reference operator reply |
| `chunks.jsonl` | no (derived, git-ignored) | the chunker output; regenerated by the command below |

## Rebuild

```bash
cd answerdesk
uv run answerdesk ingest --demo
```

The same seed (`20261020`) always produces byte-identical output. To scale the corpus to
the operating point of the requirements (≥ 3,000 documents / ≥ 20,000 chunks):

```bash
ANSWERDESK_INGEST_DOCS_PER_LOCALE=500 uv run answerdesk ingest --demo
```

Do not commit the scaled corpus: it is a build artifact of the same command.

## Provenance and license

* Generated by `answerdesk.ingest.synthetic` (`answerdesk-synthetic` 2.1.0), seed
  `20261020`, 135 documents per locale across fifteen support archetypes
  (tariff schedule, card terms, FAQ, procedure, complaint reply, KYC checklist, fee
  table, app guide, transfer limits, fraud policy, account closure, security notice,
  consumer loan, deposits/savings, remittance tracking).
* Every reference reply in `queries/queries.jsonl` is a verbatim FAQ answer of **its own**
  document: question, document and reference reply share one slot draw, and the manifest
  records the verification (`reference_grounding`: 3,240/3,240 checked, 0 findings). The
  `noisy_freeform` slice (474 items) carries the owner's reported malformed messages
  verbatim plus translations, each with an intent label and a grounded reply. See
  `docs/ingestion.md` §7.2.
* License: **CC0-1.0** (public domain dedication). No third-party text is included.
* Fictional products and reserved identifiers only (RFC 5737 IPv4, `example.*` domains,
  documented test PANs, reserved phone ranges). No real bank, brand or person is named;
  the corpus builder refuses to write a corpus that violates this policy
  (`docs/requirements.md` §13.4).
* The text is synthetic and LLM-assisted, reviewed by no native speaker: script,
  terminology, formats, quotas and grounding are tested, fluency is not. See
  `docs/ingestion.md` §12 (limitations) and the manifest's `content_provenance`.
