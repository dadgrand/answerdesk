| File | What it says |
|---|---|
| `gate.json` | machine verdict: `status`, `judged_metrics_label`, `publishable`, `synthetic`, per-language and pooled κ with bootstrap CIs, blocking `reasons`, the canonical-LF SHA-256 of every input sheet and of the policy, and a copy of the policy used |
| `gate.md` | the same verdict as a table for humans |
| `disagreements.csv` | annotator A ≠ B rows awaiting adjudication (empty while the sheets are blank) |

## How a report should consume this

```python
from judge_gate import load_judged_label

label = load_judged_label()  # "calibrated" only for an open, non-synthetic, publishable gate
```

Print the label next to every judged metric. Missing, corrupt or synthetic gates return
`diagnostic` (fail-closed). The gate opens mechanically after two humans label the sheets and
`--score` is re-run; see [`docs/judge-calibration.md`](../../docs/judge-calibration.md) §3–4.
